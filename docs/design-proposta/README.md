# Proposta visual

Desenho estático do Fiado Pro. Não é o aplicativo.

Abra `prototipos/index.html` no navegador. O CSS pede `tokens.css` na pasta de cima. Se for servir por HTTP, a raiz tem de ser esta pasta (`docs/design-proposta`), não só `prototipos/`.

## Rumo

Azul-marinho `#2B2F77`, fundo `#F6F6F4`, cartão branco, ícone de linha. Sem gradiente e sem emoji.

A conta é de qualquer pessoa. A interface diz Minha conta e Pessoas.

O Free mostra um cartão com o rótulo Patrocinado. O Pro não mostra anúncio.
